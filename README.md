# BudgetLight 💎

**BudgetLight** — это современная экосистема инструментов для личной эффективности, построенная на базе передовых Android-стандартов. Приложение сочетает в себе строгую архитектуру, реактивный интерфейс и высокий уровень безопасности данных.

---

## 🏗 Архитектура
Проект реализован с использованием **Feature-based Clean Architecture**. Весь функционал разделен на независимые модули (фичи), что обеспечивает высокую масштабируемость и легкость тестирования.

### Структура модулей:
*   **`feature:auth`** — система безопасности, регистрация и управление профилем.
*   **`feature:launcher`** — центральный хаб, точка входа во все инструменты приложения.
*   **`feature:budget`** — полнофункциональный финансовый планировщик.

### Слои внутри каждой фичи:
1.  **UI**: Jetpack Compose, Material 3, State-management (StateFlow).
2.  **Domain**: Чистая бизнес-логика (UseCase, Repository Interfaces).
3.  **Data**: Источники данных (Room, DAO, Repositories) и мапперы.

---

## 🌟 Основные возможности

### 🏠 Launcher (Главный хаб)
Центральный экран для быстрого переключения между инструментами:
*   🚀 **Budget Planner**: Мгновенный переход к управлению финансами.
*   🛒 **Shopping List**: Модуль запланирован в дорожной карте (сейчас в режиме Preview).
*   👤 **Multi-account**: Быстрая смена пользователя прямо из лаунчера.

### 💰 Бюджетный планировщик
*   **Реактивность**: Автоматическое обновление всех показателей при изменении любой транзакции.
*   **Умные лимиты**: Установка месячных ограничений по каждой категории.
*   **Архивация категорий**: Возможность убирать неиспользуемые категории без удаления их истории из прошлых месяцев.
*   **Swipe-to-Action**: Удобное управление списком транзакций через жесты.

### 🔐 Безопасность
*   **Argon2 Hashing**: Пароли не хранятся в открытом виде. Используется алгоритм Argon2 (через библиотеку Password4j), устойчивый к брутфорс-атакам.
*   **Session Management**: Надежное хранение сессии пользователя в локальном зашифрованном хранилище.

## 🛠 Технологический стек
*   **Язык**: Kotlin + Coroutines & Flow
*   **UI**: Jetpack Compose + Material 3 (Material You)
*   **DI**: Hilt (Dagger)
*   **Database**: Room (с поддержкой миграций и уникальных индексов)
*   **Navigation**: Type-safe Navigation Compose
*   **Quality Control**: Detekt, Spotless, ktlint, Android Lint

---

## 🚀 Инициализация и Flow
Приложение использует централизованное управление потоками через `ApplicationFlowViewModel`:
1.  **Unauthorized**: Экран входа/регистрации.
2.  **Launcher**: Хаб выбора инструментов (после успешного входа).
3.  **Budget**: Активная сессия планирования финансов.
